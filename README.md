# Инвентаризация бара — приложение (Kivy)

Мобильная версия того же учёта, что и `bar_inventory.py` / `bar_inventory.xlsx`:
те же категории и позиции, только вводите количество бутылок прямо в
телефоне, а не в Excel. Кнопка «Экспорт в Excel» в любой момент выгружает
всё введённое в `.xlsx` того же формата, что и раньше.

## Структура проекта

```
main.py           — экраны приложения (список категорий + позиции)
data.py           — те же данные, что в bar_inventory.py (без цен/региона)
storage.py        — сохранение введённых количеств в JSON на телефоне
export_xlsx.py    — сборка .xlsx из введённых данных (та же структура листов)
buildozer.spec    — конфигурация сборки APK
.github/workflows/build-apk.yml — сборка APK в облаке (см. ниже)
```

## 1. Проверить на компьютере (без телефона)

Kivy умеет запускаться обычным окном на компьютере — так удобно
проверять логику, прежде чем гонять сборку APK.

```bash
python3 -m venv venv
source venv/bin/activate        # на Windows: venv\Scripts\activate
pip install kivy openpyxl
python3 main.py
```

Откроется окно с тем же интерфейсом, что будет и на телефоне. Введённые
данные сохранятся в файл `inventory_data.json` рядом с программой
(на реальном телефоне — во внутренней папке приложения).

## 2. Собрать APK

Buildozer (инструмент, который собирает APK из Kivy-проекта) **официально
работает только на Linux** — напрямую на macOS не соберётся. Есть два пути:

### Вариант А — GitHub Actions (проще всего с Mac)

1. Залейте эту папку в репозиторий на GitHub.
2. Во вкладке **Actions** запустите workflow **Build APK** вручную
   (кнопка "Run workflow"), либо просто запушьте в ветку `main` —
   он запустится сам.
3. Через несколько минут в результатах запуска (Artifacts) появится
   готовый `.apk` — скачайте и установите на телефон (в настройках
   Android разрешите установку из неизвестных источников).

### Вариант Б — локально через Docker (если хочется без GitHub)

```bash
docker run -it -v "$(pwd)":/home/user/hostcwd kivy/buildozer android debug
```
Готовый `.apk` появится в папке `bin/`.

## 3. Известные ограничения текущей версии (прототип)

- Кнопка «Экспорт в Excel» пытается сразу открыть системное меню
  «Поделиться» (через `FileProvider`). Если на конкретной сборке
  Android это не сработает — приложение молча откатится к запасному
  варианту и просто покажет путь к сохранённому файлу во внутренней
  папке приложения (заберите его через файловый менеджер или
  подключив телефон к компьютеру). Это самая хрупкая часть прототипа —
  если понадобится, можно донастроить `FileProvider` в манифесте отдельно.
- Объёмы бутылок в списке крепкого алкоголя (1000/700/500 и т.д.)
  сейчас нередактируемые прямо в приложении — если у позиции появится
  необычный объём, проще донастроить `data.py` и пересобрать, либо
  доправить уже в выгруженном Excel.
- Иконки/сплэш-экрана нет — стандартные Kivy-заглушки. Можно добавить
  `icon.png` и прописать `icon.filename` в `buildozer.spec`, когда
  дойдут руки до оформления.
